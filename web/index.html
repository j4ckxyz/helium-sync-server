Connect a browser

  1. Quit Helium, then run the tweak for your system:

    macOS or Linux, in Terminal

    {{.TweakSh}}

    Windows, in PowerShell

    {{.TweakPs1}}

  2. Helium opens. Click Add extension.

  3. Sign in, or create your account{{if eq .Registration "invite"}} with an invite code (the server prints one at first start; make more with helium-sync invite){{end}}.

The tweak only switches on Helium's built-in “Always prompt for install” flag so Helium accepts the extension from this server, then opens the install page. The scripts live in the project repository; read them before running. Undo with --undo. Prefer Developer mode? Download the extension and use “Load unpacked”.

What syncs

Live tabs
Arc-style real-time mirroring of a window across devices — all tabs, or just pinned and grouped ones.
Bookmarks
Folders, order and edits, merged without duplicates.
History
New visits appear on your other devices, plus a searchable archive.
Open tabs & send tab
See other devices' tabs; send a page to any device.
Extensions
Your extension list and on/off state, with one-click install of missing ones.
Reading list
Saved for later, everywhere.

Private by design

Everything is encrypted in the browser with a key derived from your password (PBKDF2-SHA256 → HKDF → AES-256-GCM). This server only stores ciphertext and never sees your password or keys.
